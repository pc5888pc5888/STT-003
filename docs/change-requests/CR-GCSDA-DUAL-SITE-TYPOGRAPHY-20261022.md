# CR-GCSDA-DUAL-SITE-TYPOGRAPHY-20261022

Date: 2026-10-22
Requested by: Founder / site owner
Approval: YES — explicit correction that both sites must share typography, sizing and paragraph rules.

## Scope

Establish one governed typography system across STT Governance and GCSDA for equivalent semantic roles.

## Locked presentation rules

- Same serif body family
- Same Sans family for kickers / micro labels
- Body: 17px / 1.95 desktop, 16px / 1.9 mobile
- H2: 28px desktop / 24px mobile
- H3: 22px desktop / 21px mobile
- Governed Hero H1 scale: 48 / 42 / 36 desktop by title-length class
- Kicker: 11px / 1.8
- Navigation and primary actions: 15px / 1.5
- Card copy: 16px / 1.9
- Row/list prose: 17px / 1.9
- Metadata / footer: 14px / 1.7
- Narrative person-page paragraphs: 2em first-line indent
- Consecutive narrative paragraphs: 18px vertical separation
- Section rhythm: 62px desktop, 40px mobile

## Principle

Consistency means same semantic role = same type rule. Institutional differences remain in logo, color, wording, governance identity and information architecture — not arbitrary font drift.

## Unchanged

No factual copy, routes, approved images, organization identity, governance boundaries or CTA destinations are changed.
