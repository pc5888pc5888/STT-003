# DUAL-SITE TYPOGRAPHY SOURCE OF TRUTH — 2026-10-22

Status: Founder-approved presentation governance overlay
Scope: STT Governance + GCSDA public websites

## Principle

Equivalent semantic roles must use the same typography and paragraph rules across both sites.

Institutional differentiation belongs to:
- logo
- naming
- content
- color nuance
- governance identity
- information architecture

It must not be created through arbitrary font-size, line-height or paragraph drift.

## Desktop baseline

- Body / narrative: 17px, line-height 1.95, Noto Serif TC family
- H1 governed hero:
  - short: 48px / 1.35
  - medium: 42px / 1.40
  - long: 36px / 1.45
- H2: 28px / 1.55
- H3 / card heading: 22px / 1.55
- Kicker / micro heading: 11px / 1.8, Noto Sans TC family, 0.12em tracking
- Navigation: 15px / 1.5
- Primary / secondary actions: 15px / 1.5
- Card copy: 16px / 1.9
- Rows / lists: 17px / 1.9
- Metadata / footer: 14px / 1.7
- Form controls: 17px / 1.7
- Major content width: 1180px maximum

## Mobile baseline

- Body: 16px / 1.9
- H1: 29 / 27 / 25px by governed title-length class
- H2: 24px
- H3: 21px
- Form controls: 16px
- Main content horizontal width: viewport minus 48px
- Section vertical rhythm: 40px

## Paragraph rules

Narrative profile prose:
- first-line indent: 2em
- justified Traditional Chinese text where supported
- consecutive narrative paragraphs: 18px separation

No first-line indent on:
- headings
- hero text
- quotations
- lists
- qualification rows
- current-position rows
- publication rows
- CTA / buttons
- navigation
- captions / metadata

## Punctuation

H1 / H2 / H3 must not display the Chinese full stop character `。`.

## Profile-page alignment

STT /eric-chuang and GCSDA /founder-chairman use:
- the same 1672:941 portrait hero geometry
- the same type scale
- the same paragraph rhythm
- distinct body language and institutional copy

## Change control

Future page-specific CSS must not override this baseline without an explicit Change Request.
