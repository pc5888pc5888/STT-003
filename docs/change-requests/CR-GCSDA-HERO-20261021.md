## 已核對問題與原圖

目前首頁傳入 /visual-bank/gcsda/home-approved.webp，不是未傳圖片參數。
該檔實際 7495 bytes，RIFF 宣告 16526 bytes；完整解碼檢查失敗。瀏覽器 naturalWidth 或 HTTP200 不能證明圖像實際完整呈現。
現有 home.webp 為 600×338 的低解析衍生圖，不能放大冒充原圖。
既有 Library《GCSDA_全站排版修正版.html》的首頁圖像鍵為 3eeb5a932e9582c5e602；其完整內嵌圖為 1600×900，畫面是冊頁、封緘卷軸、樹與指南針，與既有 home.webp 的首頁圖像一致。
同一原圖的完整檔已在現行學會分支 public/visual-bank/gcsda/council.png 中：1672×941、1923720 bytes、SHA256 3eeb5a932e9582c5e602ff56a712e1fdd504ef4c14d9c1ebb417e9f9bfa90f42。檔名不是判斷用途的依據；本次恢復的是先前首頁圖像鍵對應的同一幅核准作品，不是隨意選另一張圖。

## 限定施工

首頁圖像解析由唯一 resolver 將已損壞 home-approved.webp 對應至現有完整原圖 council.png；不更改原始像素、不產生替代圖、不使用低解析縮圖或裁取截圖。
共用 GovernedHero 在學會現行分支增加 gcsda-hero 命名空間；以限定學會的排版規則取代先前跨站疊加的英雄區排版效果。
桌面文字保持左側穩定閱讀區，原圖置右，完整等比例顯示，白色漸層僅處理閱讀區交界；取消固定 180px 的文字下移與隨整幅圖片高度無限制拉長首屏。
手機／窄平板保持圖文分開、原圖完整、字級可讀，不把文字壓在複雜圖像上。隱私等沒有原核准底圖的頁面仍用純文字，不補造圖片。

## 驗收與發布條件

首頁實際請求完整高解析圖而非損壞 WebP；所有 8 個主視覺均做完整解碼及瀏覽器實際非空白像素檢查，不只檢查寬度。
390／768／1024／1440px 的首頁與全部頁首檢查：圖像比例、主要物件、標題／段落可見、無文字裁切與水平溢出、單一 H1、按鈕可操作；另比較更動前後全部 main 可見文字及非 Hero 圖像來源不變。
先 build 與檢查現行分支，確認後才更新同一正式 GCSDA alias；不得改指 STT 母站，也不得刪除共同承載兩站的 Vercel project。
確認正式主機對應新部署與實際資產。匿名訪問與管理連線訪問分別記錄，不把登入保護的畫面列作公開可用。
發布前以實際截圖人工檢查首頁、關於學會與手機頁首；沒有看到圖像與文字不得宣告完成。
