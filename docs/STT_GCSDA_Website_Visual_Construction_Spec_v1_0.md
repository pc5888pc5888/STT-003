# STT Governance × GCSDA｜網站施工規格稿 v1.0

適用日期：2026-09-11

## 共通原則

兩站均採白／暖白主體、深石墨文字、啞金制度性點綴；STT 是治理判斷中心，GCSDA 是治理共同體與正式機構，兩站互相導流但不混為同一品牌。

## 圖片

- Hero／滿版圖：不得使用 600px 級縮圖。Desktop 來源至少 2560px 為目標，理想 3200px 以上；若核定原圖本身僅 1672px，保留原圖，不用 AI 放大冒充新增細節。
- 一般橫幅來源至少 1600px；卡片圖至少 1200px。
- 不套低品質 filter，不先縮小再放大；人物、Logo、出版封面、正式文件不得裁切關鍵識別。
- 所有頁面圖都要有來源與用途對照；素材不足時標記待補，不以模糊圖填空。

## STT 字體

Hero H1 56–60px；Page H1 46–52px；H2 32–38px；H3 21–25px；Lead 17–18px；Body 16–17px。中文標題 Noto Serif TC、正文 Noto Sans TC、英文標籤 Inter。主標 #1F1F1F，正文 #4B4741，次文 #67615A，制度金 #9A7444。

## GCSDA 字體

Hero H1 52–58px；Page H1 44–50px；H2 31–36px；H3 21–24px；Body 16px。中文標題 Noto Serif TC，正文 Noto Sans TC，機構標籤 Inter／Noto Sans TC。主標 #22201D，正文 #514B45，制度金 #967044。

## 標題呈現

主標不可過大；Hero、Section、Card 必須有清楚級差。完整雙句標題遇第二個完整句子時換行；逗號、分號不強制換行。淡金線只做制度分隔，不把每個卡片都框成表格。

## GCSDA 圖片語義

章程、會員、議事、理監事、共同體、研究、活動、產學研交流為主；不得因風格相近而把 STT 判讀／AI／出版圖無差別搬入學會網站。

## 待補素材

GCSDA：正式 Logo 向量檔與透明 PNG；第一屆理監事正式團體照；理事長正式肖像；會員大會／理監事聯席會現場照；正式文件與授證照片；活動橫式主圖與現場照片。原檔建議短邊 3000px 以上。

## 連結驗收

所有可點擊元素必須有真實目標。不得存在空 `#`、不存在路由、未掛檔案的下載按鈕、或看似可點但無行為的卡片。尚未取得真實目標 URL／文件／表單的入口先標記未啟用，不建立假連結。
