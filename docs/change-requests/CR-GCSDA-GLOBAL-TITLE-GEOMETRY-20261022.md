Date: 2026-10-22

## Global rule

All GCSDA page-title heroes now use the same title geometry as the approved STT screenshot:
- desktop copy top: 180px
- desktop copy left: 56px
- H1: 48px / 1.38
- Kicker: 11px / 1.8
- Lead: 17px / 1.95
- no title-length-based H1 shrinkage

A GCSDA-specific specificity override is written in gcsda-hero-repair.css so legacy association Hero rules cannot win the cascade.

Text-only public pages use the same title origin.

No copy, route, navigation, image asset or institutional identity is changed.
