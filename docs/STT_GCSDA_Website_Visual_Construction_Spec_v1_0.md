# STT Governance × GCSDA｜網站施工規格稿 v1.0

適用日期：2026-09-11

## 1. 共通視覺治理原則

兩站均採「白／暖白承載內容、深石墨建立權威、啞金標示制度秩序」；但定位不得混同：STT Governance 是治理判斷中心，GCSDA 是治理共同體與正式機構。兩站互相導流，不製造上下級錯覺。

## 2. 圖片品質標準

1. 網站不得以 600px 級縮圖作為主視覺來源。
2. Hero／滿版主視覺：優先直接使用既有核定原圖；Desktop 建議來源寬度至少 2560px，理想 3200px 以上；若原始核定檔僅 1672px，保留原圖，不得用 AI 或一般放大冒充新增細節。
3. 一般橫幅／內容主圖：來源寬度至少 1600px；卡片圖至少 1200px。
4. 不使用 CSS filter、低品質二次壓縮、先縮小再放大。
5. 以 `object-fit: cover` 僅作構圖裁切，不得降低來源像素；重要出版封面、文件、人物照片優先 `contain`，避免裁掉文字、臉部與正式識別。
6. Retina 驗收：圖片實際顯示的物理像素需求不得明顯高於來源有效像素；若來源不足，標記為「待補原圖」，不得宣稱最高解析度完成。
7. 所有新圖片來源都要保留原始檔名／來源紀錄與使用頁面對照，不任意重製。

## 3. STT Typography System

- Hero H1：Noto Serif TC；Desktop 56–60px；Tablet 44–48px；Mobile 34–38px；weight 550–600；line-height 1.24–1.32；#1F1F1F。
- Page H1：46–52px；Mobile 31–36px。
- Section H2：32–38px；Mobile 25–30px。
- H3：21–25px；Mobile 19–22px。
- Lead：17–18px；line-height 1.85–1.95；#5F5952。
- Body：16–17px；line-height 1.9–2.0；#4B4741。
- Eyebrow／English label：Inter；10–12px；letter-spacing .14–.20em；#9A7444。
- 導覽：14–15px；#4B4741。

中文標題使用 Serif，中文正文與操作文字使用 Sans；英文標籤使用 Inter。避免所有標題同樣粗黑；以字重、留白與淡金索引建立層級。

## 4. GCSDA Typography System

GCSDA 沿用同一字體家族，但語氣比 STT 稍具正式機構性：

- Hero H1：52–58px；weight 550；#22201D。
- Page H1：44–50px。
- Section H2：31–36px。
- H3：21–24px。
- Body：16px；line-height 1.9；#514B45。
- 機構標籤／章程索引／職稱：Inter 或 Noto Sans TC，使用 #967044，不以大面積金色文字呈現。

## 5. 標題呈現規則

1. 主標題不可為了裝飾而過度放大；Hero 與 Section 必須有清楚級差。
2. 中文標題以自然語意換行；句子中有兩個完整句點時，第二句自新行開始。逗號、分號不視為強制換行。
3. 標題前可使用小型英文／制度標籤，但不得每區都機械複製。
4. 淡金線僅作制度分隔，不以粗框包住所有卡片。
5. 主標、導語、按鈕之間以留白建立層級，不使用多餘陰影或強烈漸層。

## 6. 雙站圖片語義

STT：判讀、證據、決策、權責、家族、AI、人機治憲、出版研究。

GCSDA：章程、會員、議事、理監事、共同體、研究、活動、產學研交流。

同一張圖片不得因為風格一致就跨站任意複製；必須有頁面語義依據。

## 7. 必備照片與內容資產缺口

### STT 建議補充

- 莊鈞翔博士正式治理肖像：至少 2 組，直式半身與橫式環境肖像；原檔建議短邊 3000px 以上。
- 實際治理／講座／會議現場：5–10 張可公開原圖，用於「治理責任」「合作／委託」而非全部使用概念圖。
- 實體著作高解析封面／書封原檔：每本正面與立體書主圖。
- 若要呈現媒體、出版、研究合作，需正式授權的 Logo／機構識別原檔。

### GCSDA 建議補充

- 學會正式 Logo 向量檔（SVG／PDF／AI 其一）與透明 PNG。
- 第一屆理監事正式團體照 1 張，原檔短邊至少 3000px。
- 理事長正式肖像 1–2 張。
- 第一屆會員大會／理監事聯席會現場照 8–15 張：含全景、致詞、合照、議事、交流。
- 學會正式文件照片：立案證書、章程封面、會議資料或授證照片；公開版需確認個資遮蔽。
- 未來活動頁每場至少 1 張橫式 16:9 主圖＋3–6 張現場圖。

## 8. 連結／功能驗收

所有可點擊元素必須被分類為：內部頁面、外部正式來源、表單／聯絡、下載文件、純錨點。不得存在空 `#`、不存在路由、未掛文件的下載按鈕或看似可點但沒有行為的卡片。

STT 每次發布至少驗收：首頁、五個主題頁、開始入口、212 則專欄原文、出版／研究入口、莊博士責任頁、STT↔GCSDA 導流。

GCSDA 每次發布至少驗收：首頁、關於學會、組織治理、策略治理聯席會、會員與入會、活動與大會、知識與研究、章程與公告、STT 制度入口、LINE／表單／外部機構連結。

任何尚未取得真實目標 URL／文件／表單的按鈕，先改為不可操作說明，不得假連結。
