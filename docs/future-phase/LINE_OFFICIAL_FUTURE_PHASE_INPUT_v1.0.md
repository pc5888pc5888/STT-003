## 3. Welcome message — review draft

歡迎來到 STT Governance。

STT Governance 協助企業、家族與重大決策者，在結果尚未不可逆之前，先釐清問題、證據、權力、責任、選項與不可承擔風險，再決定是否行動，以及如何形成可承擔、可追溯的治理結構。

你可以直接從下方圖文選單開始：
「你正在面對什麼」— 先辨識目前事件的治理層級。
「STT 如何判讀」— 理解 STT 在採取行動前如何完成判讀。
「治理委任」— 理解正式介入方式、成果與專業邊界。
「研究與出版」— 閱讀 STT 的研究、出版與公開內容。
「關於 STT」— 理解 STT 的機構定位與治理方法。
「開始治理判讀」— 進入正式治理受理。

本帳號以正式資訊導引與治理受理為目的，不以促銷、即時成交或一般客服為主要功能。

## 4. Default fallback reply — review draft

這裡是 STT Governance 官方資訊入口。

若你正在面對企業重大決策、家族與接班、股權與治理權、法遵壓力，或 AI 進入決策流程後的權責問題，建議先從「你正在面對什麼」開始。

若事件已跨越單一專業、單一部門或單一家庭成員可以獨立處理的範圍，可直接進入「開始治理判讀」，先把現在發生了什麼、最不希望接下來發生什麼，以及希望最後形成什麼狀態說清楚。

第一次提交只整理問題與下一步，不要求大量敏感資料。

## 6. Rich menu visual rule

- six-cell layout only
- warm white / ivory background
- near-black warm gray typography
- low-saturation classical gold used only for institutional lines, boundaries, and the primary CTA
- large text labels with high mobile legibility
- no photography required
- no AI iconography
- no technology blue
- no neon
- no robot / brain / chip imagery
- no SaaS dashboard visual language
- no sales badges, discount language, urgency devices, or promotional stickers

Recommended hierarchy:
- five institutional entry cells use equal visual weight
- 「開始治理判讀」 is the only cell allowed a stronger gold boundary or emphasis
- the menu must remain readable when viewed at native LINE chat width

## 7. Explicit exclusions

The following legacy concepts are excluded:
- ebook sales funnel
- bestseller promotion
- reader discount / limited benefit
- author recruitment
- interview-booking funnel
- 30-day publishing plan
- project interview process
- booking a director
- generic lead-generation funnel
- any second brand language separate from the website
